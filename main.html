Cerita Singkat Tentang Saya

Halo! Saya Lukman, siswa SMKN 1 Bangsri jurusan PPLG (Pengembangan Perangkat Lunak dan Gim). Saya memiliki minat dan semangat besar dalam dunia coding dan pengembangan web.

Dengan dasar HTML, CSS, dan JavaScript, serta framework seperti TailwindCSS, saya terus mengikuti perkembangan teknologi dan berupaya meningkatkan skill dalam mengembangkan web dan aplikasi.

Selain itu, saya juga memiliki kemampuan dalam desain UI/UX menggunakan Figma, yang membantu saya dalam membuat tampilan yang menarik dan user-friendly.
